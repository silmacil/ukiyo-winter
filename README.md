# Ukiyo Winter

A woodblock-print look for the Claude desktop app: a moonlit castle in falling snow, quiet before battle.

- **The scene:** Mt Fuji under snow, a castle keep with lit windows, war banners on the outer wall, a war camp with its curtain and watch fires, three samurai guards standing watch, a snow-laden pine, and the grain of the woodblock showing through the sky. Snow falls slowly, banners stir, fires glow.
- **Context as the night wearing on:** as the conversation's context window fills, the night pales and the moon sinks; from about 60% a band of dawn rises across the whole sky, deepening toward 95%. When the conversation compacts, dawn breaks and a fresh night begins.
- **Messages:** yours on a paper slip with a small cinnabar seal, Claude's on black lacquer (by day, pale cedar), each edged with a single fine line. Serif type throughout.
- **Both modes:** dark mode is the moonlit night; light mode is the same scene by day, as a grey snow print.

The look is data the app draws, so it does not replace or hide any of the app's features, and app updates keep working under it.

## Install

At the prompt of a terminal session:

```
/plugin install ukiyo-winter --marketplace silmacil/ukiyo-winter
```

Answer `y` to add the marketplace, then choose a scope (the user scope is first).

From a shell:

```
claude plugin install ukiyo-winter --marketplace silmacil/ukiyo-winter
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `silmacil/ukiyo-winter`, then Add plugin.

## Use

The mod does nothing until you turn it on:

- `/ukiyo on` sets the look. It stays on in later sessions.
- `/ukiyo off` brings back the app's own look.
- `/ukiyo` says whether it is on.

The scene, frames and type draw in the desktop and mobile apps; the terminal keeps its own look. If your app refuses part of the look, the mod steps down to what it accepts (scene and colors, or colors alone) and says so.

## Notes

- `hooks/art.js` (the scene, frames and palette) was generated by a builder that isn't part of this repository; it is plain SVG and JSON, so small edits by hand are fine.
- `hooks/make-colors.js` is the theme color helper from Claude's mod-authoring kit, copied as it is.
- The crests and the seal are invented; no real clan's mon is used.
